## Four-Factor Command Envelope (C-2)

Every wire-originated command MUST present:

| Header              | Purpose                                                                |
|---------------------|------------------------------------------------------------------------|
| `X-ARIA-Counter`    | Monotonically-increasing 64-bit per-source counter (replay defence).   |
| `X-ARIA-Nonce`      | ≥ 16 bytes random.  Prevents content collision on the same counter.    |
| `X-ARIA-Timestamp`  | DSN light-time-tolerant window (LEO 30 s / Lunar 30 s + 2.6 s / Mars 30 s + 22 min). |
| `X-ARIA-Signature`  | Dual: Ed25519 (classical) ‖ ML-DSA-65 (post-quantum).  `require_pq=True` in production. |

`api/command_envelope.parse_and_verify` returns an `EnvelopeVerdict` carrying the verified principal — no caller can forge identity.  `sign_envelope` is the writer-side counterpart for ground software.
